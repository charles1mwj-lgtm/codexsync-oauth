CodexSync

CodexSync is a personal desktop synchronization utility designed to keep a user's own files synchronized between trusted computers through Google Drive.

Purpose

CodexSync connects to the user's Google Drive account only after the user grants permission. It is used to upload, download, and synchronize the user's own data between authorized devices.

Data handling

CodexSync does not sell user data and does not share user data with third parties. Files remain under the user's control in the user's own Google Drive account.

Privacy

For details, please read the CodexSync Privacy Policy.
