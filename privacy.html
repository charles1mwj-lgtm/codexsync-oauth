CodexSync Privacy Policy

Last updated: September 5, 2026

CodexSync is a personal desktop synchronization utility. It is intended for use by the account owner to synchronize the owner's own files between trusted computers through Google Drive.

Information accessed

When the user authorizes CodexSync with Google OAuth, the application may access files and folders in the user's Google Drive as required to perform synchronization. Access occurs only after the user explicitly grants permission.

How data is used

Google Drive access is used solely to upload, download, compare, back up, and synchronize the user's own files between authorized devices.

Data sharing

CodexSync does not sell, rent, or share Google user data with advertisers or unrelated third parties.

Data storage

Synchronized files are stored in the user's own Google Drive account and on the user's own computers. Local OAuth credentials may be stored on the user's device so the application can operate without requiring sign-in every time.

Data retention and deletion

The user controls the synchronized files and may delete them from Google Drive or local devices at any time. The user can also revoke CodexSync's Google account access from Google Account security settings.

Security

CodexSync is designed for personal use on trusted devices. Users should protect their operating-system account, OAuth credentials, and cloud account with appropriate security controls.

Contact

For privacy questions, use the contact email configured for the CodexSync OAuth application in Google Cloud Console.
